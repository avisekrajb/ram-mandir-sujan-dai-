# 🕉 Shree Ramchandra Temple Website

A full-stack MERN application for Shree Ramchandra Temple, Gaushala, Kathmandu.

## Features

- 🏛️ Temple information and history
- 📅 Event management
- 📸 Gallery with photos and videos
- 🙏 Online puja booking
- 💰 Donation management
- 👥 User authentication with JWT
- 🌐 Multi-language support (EN, NE, HI, ZH, TA)
- 🖼️ Cloudinary media upload
- 📱 Fully responsive design

## Tech Stack

**Frontend:**
- React 18
- React Router v6
- Tailwind CSS
- Lucide Icons
- Axios

**Backend:**
- Node.js
- Express
- MongoDB Atlas
- Mongoose
- JWT Authentication
- Cloudinary
- Nodemailer
